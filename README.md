# Haunted Pairs

A Halloween memory card game for M1 · El Despertar del DOM, currently in development.

## Current functionality

The page displays eight Halloween creature buttons. Clicking a button shows the
creature's name. The styling is basic and no card matching tyet.

## How to run

For now, `index.html` in a browser. The project uses separate HTML, CSS, and JavaScript.
